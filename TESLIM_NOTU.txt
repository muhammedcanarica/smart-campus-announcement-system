Akıllı Kampüs Duyuru ve Bildirim Yönetim Sistemi

1. Web GUI Demo:
https://muhammedcanarica.github.io/smart-campus-announcement-system/

2. GitHub Repo:
https://github.com/muhammedcanarica/smart-campus-announcement-system

3. Maven ile çalıştırma:
mvn clean package

Windows Maven Wrapper:
.\mvnw.cmd clean package

Linux/macOS Maven Wrapper:
./mvnw clean package

JAR çalıştırma:
java -Dfile.encoding=UTF-8 -jar target/smart-campus-announcement-system-1.0-SNAPSHOT.jar

Not:
Web GUI demo, Java console uygulamasındaki duyuru ve bildirim akışını görsel olarak simüle eder.
Ana kaynak kod Java Maven projesi olarak repoda bulunmaktadır.
